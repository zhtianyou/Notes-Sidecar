# Notes Sidecar 上线介绍资料（简体中文）

更新：2026-10-07  
定位：macOS 上与 Apple Notes 并排工作的私密 AI 对话助手。

> 使用边界：以下文案只描述当前已实现并经本机构建验证的能力。模型输出仍取决于用户自行选择并配置的服务商；不要承诺准确性、实时性或第三方服务可用性。

## 一句话介绍

Notes Sidecar 让 AI 对话贴在正在阅读的 Apple Notes 旁边；无需先把笔记复制到聊天框。

## 面向谁

- 在 Apple Notes 中整理项目、研究、会议记录或个人资料的 Mac 用户。
- 希望自行选择 AI 服务商与模型，并把 API Key 留在本机的人。
- 重视“当前笔记是什么、这轮对话就围绕什么”的清晰上下文的人。

## 核心卖点

1. **每篇笔记都有自己的对话上下文**  
   读取当前选中的 Notes 笔记；切换笔记时，Sidecar 自动切换到对应对话，避免不同主题串台。

2. **不需要把笔记粘进输入框**  
   用户直接提问，当前笔记是对话依据。快捷操作可直接执行总结、提取任务、整理结构或发现缺口。

3. **先在本机做隐私检查**  
   发送前对文本和图片本地识别；检测到凭证、Token、密钥等敏感内容时，相关内容不发送给 AI，并清楚提示用户。图片仅做本地识别，原图不上传。

4. **用户自带模型，直连服务商**  
   支持 Anthropic、OpenAI、DeepSeek、Moonshot、智谱 GLM、MiniMax、Ollama 和 OpenAI 兼容服务。请求从这台 Mac 直达用户选定的服务商；开发者不提供中转服务器。

5. **本地优先的凭证与会话**  
   API Key 存储在 macOS Keychain；按笔记保存对话和草稿。Ollama 可用于本地模型工作流。

6. **把结果安全放回笔记**  
   支持插入备忘录或新建笔记，并在写回前提供预览与冲突保护，减少覆盖原文的风险。

7. **为真实桌面工作流设计**  
   可固定在最前、最小化、与 Notes 窗口并排或独立使用；提供浅色、深色、科技感三套外观，界面自动跟随简体中文或英文系统语言。

## App Store 元数据草案

### 名称

`Notes Sidecar`

建议先在 App Store Connect 检查可用性；名称不可用时备选：`Notes Sidecar AI`、`Sidecar for Notes`。

### 副标题（选一）

- 与 Apple Notes 并排的私密 AI 对话
- 围绕当前笔记直接问 AI

### 推广文案（170 字符内）

直接围绕当前备忘录提问。每篇笔记各自保留对话，模型服务商由你选择，敏感内容先在本机过滤再发送。

### 长描述

Notes Sidecar 把 AI 对话放在 Apple Notes 的一侧。打开边栏、选中一篇笔记、直接提问即可：笔记持续作为上下文，而输入框只承载你的问题，不必把整篇笔记复制粘贴进去。

每篇笔记各自拥有对话。切换备忘录时，Sidecar 自动切换到对应会话，让会议纪要、研究资料和个人清单互不串台。内置快捷操作可以总结、提取任务、重组结构和发现缺口。

隐私检查发生在发送之前。文本与图片先在本机识别；发现敏感内容后，相关部分会被排除，并提示原因。图片仅用于本地识别，原图不会作为识别内容上传。

你可以自行选择并配置 Anthropic、OpenAI、DeepSeek、Moonshot、智谱 GLM、MiniMax、Ollama 或 OpenAI 兼容服务。请求从你的 Mac 直连所选服务商，API Key 保存在 macOS Keychain。

当结果需要回写时，先预览，再决定插入当前备忘录或创建新备忘录；冲突保护可降低覆盖原文的风险。

支持浅色、深色和科技感外观；macOS 为简体中文时显示简体中文，否则统一显示英文。

## 30 秒演示脚本

1. 在 Notes 打开一篇演示项目笔记，Sidecar 自动显示该笔记标题与已有对话。
2. 输入“提取负责人和截止日期”，展示流式回答与任务结构。
3. 切换到另一篇笔记，展示 Sidecar 自动切换到该笔记的独立会话。
4. 打开隐私提示示例，说明发现敏感上下文时会排除后再发送。
5. 打开 Provider 设置，展示用户可选择云端服务商或本地 Ollama，以及 API Key 本机 Keychain 保存。
6. 选择“插入备忘录”，展示写回预览而不是直接覆盖内容。
