Notes Sidecar Support

Notes Sidecar is a privacy-first macOS companion for the Apple Note you choose and your own AI provider account.

Getting started

  1. Open Notes Sidecar.
  2. Add a provider in Settings → Model Providers.
  3. Add your API key or sign in where supported.
  4. Select a note in Apple Notes, open Notes Sidecar, and review privacy notices before sending content to an external provider.

Permissions

  • Automation: reads the Apple Note you actively select and, after confirmation, appends a response.
  • Accessibility: optional; used only for window docking and reading window position.
  • Keychain: stores provider credentials locally.
  • Local processing: image and supported audio context are derived on-device and privacy-filtered before they may be sent to a provider.

Troubleshooting

Apple Notes cannot be read: In macOS System Settings → Privacy & Security → Automation, allow Notes Sidecar to control Apple Notes. Otherwise use Paste Mode.

A provider test fails: Check the key, selected model, account credit or plan, and network connection.

No response appears: Read the provider error, then confirm that the selected model supports ordinary chat and that your provider account is active.
